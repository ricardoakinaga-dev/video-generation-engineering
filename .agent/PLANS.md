# Local plan convention

This greenfield project is in a documentation-first architecture phase. The living plan is under `.agent/plans/`; `docs/` owns product and technical decisions; `.agent/state.json` owns the current pointer; `.agent/backlog.json` owns task status and one next action; and JSONL ledgers own chronology and verification evidence. The future production Skill is explicitly out of scope until the documentation acceptance matrix passes. The active expanded Phase 0 plan is `.agent/plans/phase0-master-prompt.md`; the Gauntlet run and frozen bar are under `.gauntlet/`.
