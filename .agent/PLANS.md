# Local plan convention

This repository began as a greenfield documentation-first architecture phase and now contains the authorized mature production Skill. The current project profile is `BROWNFIELD`; the historical Phase 0/R1/R2/R3 boundaries remain preserved in their own documents. The living plan is under `.agent/plans/`; `docs/` owns product and technical decisions; `.agent/state.json` owns the current pointer; `.agent/backlog.json` owns task status and one next action; and JSONL ledgers own chronology and verification evidence. The active R4 plan is `.agent/plans/triple-aaa-r4-closure.md`; the historical plans remain available; the historical Gauntlet run and frozen bars are under `.gauntlet/` and `docs/`.
