# Local plan convention

This repository began as a greenfield documentation-first architecture phase and now contains the authorized mature production Skill. The current project profile is `BROWNFIELD`; the historical Phase 0 boundary remains preserved in its own documents. The living plan is under `.agent/plans/`; `docs/` owns product and technical decisions; `.agent/state.json` owns the current pointer; `.agent/backlog.json` owns task status and one next action; and JSONL ledgers own chronology and verification evidence. The active R2 plan is `.agent/plans/triple-aaa-r2-closure.md`; the historical Phase 0 plan is `.agent/plans/phase0-master-prompt.md`; the Gauntlet run and frozen bar are under `.gauntlet/`.
