## Architecture and Interfaces

The preserved flow is `intent → canonical plan/state → risk-shaped prompt → feature adapter → runtime attempt → artifact bytes → mechanical/semantic observation → transition/repair → assembly → editorial decision`. Prompt views are derived and never evidence. Each adapter receives the same validated canonical source. Each production PASS is bound to exact bytes, a strong oracle, limitations and immutable lineage.
