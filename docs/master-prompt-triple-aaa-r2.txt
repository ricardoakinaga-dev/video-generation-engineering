# 67. DO NOT GAME THE QUALITY BAR

Forbidden:

* adding tests solely to increase test count;
* adding requirements solely to increase coverage;
* marking unknown capabilities inferred;
* using documentation as proof;
* using contact sheets as proof of all video semantics;
* calling generated bytes a successful scene automatically;
* calling one short successful clip long-form validation;
* broad-confirming a model based on one feature;
* reporting stale critic evidence;
* hiding failures by regenerating evidence artifacts.

Preserve failed evidence.

# 70. FINAL QUALITY PRINCIPLE

The project reaches State-of-the-Art quality when it does not merely write sophisticated prompts.

It must reliably transform creative intent into an inspectable production system:

INTENT
+
STATE
+
REFERENCES
+
STORY
+
SHOTS
+
PERFORMANCE
+
INTERACTION
+
CAMERA
+
AUDIO
+
MODEL CAPABILITY
+
EXECUTION
+
OBSERVATION
+
REPAIR
+
ASSEMBLY.

The final system must always distinguish:

WHAT WE WANT

from:

WHAT WE PLANNED

from:

WHAT WE EXECUTED

from:

WHAT THE MODEL ACTUALLY PRODUCED.

That distinction is non-negotiable.

# 71. START NOW

Begin by auditing the current repository state.

Do not ask for permission to make safe repository-local improvements that are clearly required by this task.

Do not execute paid APIs, upload private data, download major model weights, publish media, or perform external side effects without authorization.

Use the available local runtime where appropriate and safe.

If a requested runtime capability is unavailable:

mark it honestly as:

BLOCKED
UNKNOWN
or
NOT_RUN.

Do not stop at documentation.

Where execution is possible:

test the real system.

Where artifact observation is possible:

inspect the real output.

Where a failure occurs:

preserve the failure evidence and repair the smallest responsible layer.

The goal is not more complexity.

The goal is:

LESS UNPROVEN BEHAVIOR,
MORE OBSERVED CORRECTNESS,
STRONGER CONTINUITY,
BETTER PRODUCTION RESULTS,
AND A GENUINELY STATE-OF-THE-ART VIDEO GENERATION ENGINEERING SKILL.
